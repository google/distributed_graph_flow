ComponentA node feature, an edge feature, an edgeset or a nodeset of the graph.
Component importanceHow much the model relies on a component to make its predictions. It is measured by perturbing the component and recording the degradation of the model quality. Components are ranked by Δ Loss.
PerturbationDestruction of the information carried by a component, while leaving the rest of the graph untouched. Feature values are shuffled across nodes or edges. Edgesets are rewired (by default, with degree-preserving Maslov-Sneppen swaps, so that every node keeps its number of neighbors). Nodesets have all their features shuffled and all their incident edgesets rewired.
BaselineQuality of the model on the unperturbed graph, on the same seed nodes.
Δ LossIncrease of the loss when the component is perturbed. Larger is more important. A value close to zero means the model can do without the component (possibly because other components carry the same information).
Δ AccuracyDrop of the accuracy when the component is perturbed. Larger is more important.
Gradient saliencyAverage magnitude of the gradient of the loss with respect to the values of a feature, on the unperturbed graph. It measures how sensitive the model is to small changes of the feature. Only available for numerical features. A high saliency with a small Δ Loss indicates a feature used by the model but redundant with other features.
